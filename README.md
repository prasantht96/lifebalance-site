# LifeBalance site

Static site for the LifeBalance Android app (`com.lifebalance.app`). Plain HTML plus one CSS file (`assets/style.css`). No build step, no scripts, no trackers, no external fonts.

Live URL: https://prasantht96.github.io/lifebalance-site/

## Pages

index.html, privacy.html, terms.html, support.html, delete-data.html, 404.html, plus robots.txt, sitemap.xml and .nojekyll. MET Norway, CPCB and GeoNames attribution is in the footer of every page. There is no refunds page (free app).

## Publish (GitHub Pages)

1. Create the repo `prasantht96/lifebalance-site` on GitHub (public).
2. Push this folder to the `main` branch.
3. In the repo go to Settings, Pages, set Source to "Deploy from a branch", Branch `main`, folder `/ (root)`.
4. Wait a minute, then open the live URL above.
